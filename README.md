and Built-in Revision game in Arcade Section quiz!

Most Portfolios have same looking old flat cards with same old github link (i have not added a single link for contact me in this project lol).This project breaks down my journey from gaming to game develoment and to acoustic Guitar (spanish classical btw) and the best joining Hack Club.

the Main Uniqueness and Centre of Attraction (hardest for me to make btw) is THE ARCADE REVISION QUIZ.
Instead of letting ppl just scroll away my project and ignore them (feels bad :( ) this site challenges them on what they actually  paid attention to. It pulls questions straight from the page content (use that feature and let me know) It features locked button inputs to stop click-spamming,live status feedback,custom score calculation (was prob har for me as its my first time in web dev) and a full relay loop.

#what i used!!

1.HTML- I have used html to write the basic structure of code hero banner timeline etc

2.CSS3- I have used built in css (idk why but found it satisfying) that give colour to all the website colors such that #728e6d,#35572c,#e5cd82 and etc and made the web site LITTLE RESPOINSIVE NOT TOTALLY.

3.Vanilla Javascript- Powers the whole arcade quizz game and is the most important and hard part of the game and was not easy to learn,button locking ,answer verification etc is possible due to javascript 

4.typed.js- the cool smooth animated text effect in the hero header to cycle trought skills and community roles is a fortune to have.


#what i learned!

1.CSS Responsiveness: the website itself is not totally web responsive to every screen (DO NOT EXPECT TO RUN THIS IN IPHONE DUO) but switching from rigid marins to responsive grid templetes.

2.DOM querying vs IDs: Fixing tricky selector bugs (i was resonsible for them )

3.State & Event handling: Tracking score and indices cleanly in plain JS without global variable chaos,plus using timeouts to delay question transition smoothly was painfull.

Got my hands Dirty and actually building stuff beats watcing tutorials all day every day and got to learn plenty.
